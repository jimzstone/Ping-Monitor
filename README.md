# Ping Monitor

A compact Windows application for monitoring ping, packet loss, and connection status.

**Free to use. No monthly payments or subscription required. Donations are optional.**

## Download and get started

Download **Ping-Monitoring.zip** from this repository or its Releases page.

1. Extract the ZIP to a permanent folder.
2. Open **PingMonitor.exe**.
3. Enter a website or IP address, such as `google.com`.
4. Choose your appearance and placement settings.
5. Click **Start / Apply**.

Requires Windows with .NET Framework 4.x. Exit older copies before upgrading.

## Features

- Live ping and packet-loss statistics in a compact two-line panel.
- Happy, dizzy, and dead connection faces.
- Dark/light mode, custom borders, and transparency.
- Draggable or taskbar-locked placement.
- Background monitoring during fullscreen apps.
- Optional automatic Windows startup.
- Pause/resume, connection details, and CSV export.
- Speedtest.net shortcut and in-app instructions.
- Optional donation QR codes for MariBank, GCash, and Maya.

## Controls

Right-click the panel or tray icon for settings and controls. Double-click to open settings.
Disable **Lock panel beside taskbar icons** to drag the panel. Use **Exit** to close it.

Ping checks ICMP reachability, not HTTP website health. Some websites block ping while still working normally.
